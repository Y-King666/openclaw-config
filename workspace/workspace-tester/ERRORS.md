## 📋 Error Logging Standards

**Each error record should include:**

| Field | Description | Example |
|------|------|------|
| **Error Context** | Circumstances under which the error occurred | "While editing a file using the edit tool" |
| **Error Message** | The actual error message | `Could not find the exact text` |
| **Root Cause** | Why the error happened | "Assumed file content without reading to confirm first" |
| **Correct Practice** | How to avoid/resolve it | "Must read the file to confirm actual content before using edit" |
| **Occurrences** | Cumulative count | 2 times |
| **Last Occurred** | Timestamp of the most recent occurrence | 2026-02-28 |
