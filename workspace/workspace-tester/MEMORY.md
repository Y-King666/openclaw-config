## Core Knowledge

### Skill Rules

#### Pre-installation

- Must perform risk assessments and scan skill files. Installation is only permitted if the risk is low and no malicious scripts are present.

#### Post-installation

- Skills must be configured and tested. They are only retained if testing passes; otherwise, they must be removed.

### Language Rules

- **Communication:** Always use Chinese for all direct interactions and conversations with the user.
- **Documentation & Files:** Use idiomatic English for all workspace files, documentation, and code artifacts, with the exception of specific proper names such as the user's name (琪哥/老大) and the assistant's name (贾维斯).
